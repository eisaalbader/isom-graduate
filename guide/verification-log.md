### The address

### The code itself

`guide/mkqr.py` draws it. Three decisions, all made against a decoder rather
than by eye:

- **Error correction Q, not H.** H would have needed 33 modules for this
  address; Q needs 29. Fewer modules means each one is physically larger at
  print size, and that — not styling — is what makes a code scan. Q still
  tolerates about a quarter of the code being obscured, which the club mark in
  the middle uses 15% of.
- **Square modules, square eyes.** The first version rounded both. It looked
  better and no decoder could read it, at any size. Rounded geometry distorts
  the 1:1:3:1:1 ratio the finder patterns are recognised by and breaks the
  timing runs between modules. It was reverted.
- **28mm on the sheet.** At 24mm the code scanned on an A2 print but was
  marginal on an A4 reprint. The 4mm came out of the OSCM row minimum
  (`.grid--roomy`, 44mm → 40mm), which no check and no reader will notice.

`mkqr.py` refuses to save a code it cannot decode back. `qrcheck.py` goes
further: it rasterises each finished **PDF** at 300dpi for A2, A3 and A4 and
decodes the code out of the printed page. All six sheets pass at all three
sizes. A code that decodes in the design tool and not on the wall is the entire
failure mode, so the check is on the artefact that gets printed.

### The footer

The QR was 17mm in a corner. It now leads the footer as a framed block with the
tool's name in both languages, one line saying what it does, and the address in
plain text beside it — because a printed sheet should still work for someone
whose phone cannot scan. The MIS page had been carrying its own hand-written
footer since the first build and so had quietly missed every footer change made
since; it now uses the shared one like the other five.

### What a second reader found, and what was done

An independent pass over all seven rendered sheets turned up five real faults.
All are fixed; the reviewer's sixth point is recorded and rejected.

**One course, two English names.** 1013205 read *Modeling & Decision Making* on
the General page and *Intro. to Modeling & Decision Making* on the OSCM page,
and 1013210 the same way — while the Arabic on both pages said مقدمة في
(“Introduction to”). So the English did not match its own Arabic on the same
card, before it disagreed with the other page. Both are now **Introduction
to …** everywhere, matching the Arabic and matching 1013240, which was already
spelled out in full.

**Course numbers in Arabic-Indic digits.** Eight strings still carried them:
the seven OSCM elective prerequisite chips (بعد ١٠١٣٣١٦) and the General page's
closing banner. Page 06 states the rule in its own footer — *course numbers are
always written in English digits, because that is how you type them* — so the
guide was contradicting itself on two sheets. All eight now use English digits.
Counts (٣٠ وحدة, ١٣٠ للتخرج) are untouched; they are counts, not numbers anyone
types.

**Two colour names that did not match their own translation.** The MIS legend
said *Green-grey* against الرمادي (grey); the swatch is olive, and the electives
page already called the same colour الزيتوني. It is **Olive / الزيتوني** on both
now. The General legend said *Red* against العنابي (maroon) where every other
sheet says الأحمر; it now says الأحمر.

**A colour claim the page could not keep.** The General page said card colours
show which department teaches the course, but 1060307 is purple with the
business subjects while Public Administration teaches it. The caption now says
the colours **group the courses by subject**, which is what they actually do,
and the purple key reads *business subjects* rather than naming departments.

**The cover said less in Arabic than in English.** The lockup read ISOM CLUB ·
KUWAIT UNIVERSITY above نادي نظم المعلومات وإدارة العمليات — the university
missing from the Arabic half. It now names both in both languages.

**Rejected:** the reviewer flagged 0460113 and 0494105 as printed without a
caveat. That is the club's own decision, taken on 20 Sep and recorded in
section N. The finding stands in this log; the page stays as the club asked.
